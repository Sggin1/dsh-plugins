# Security

These plugins fetch data over the network and write DSH settings, so a security report is welcome.

**Please report a vulnerability privately**, using this repository's *Security* tab and *Report a vulnerability*
(GitHub's private vulnerability reporting). Please do not open a public issue for a security problem.

Useful details: the plugin and version (commit), what you did, what you expected, and what happened.

## After you report

I will read it and reply when I can. If it is a real problem I will fix it and say so in this repository, and credit you if you
want. If I cannot fix it I will say that too. Please keep the details private until a fix is out; I will share the details only
after it is fixed, and only with your OK.

These plugins are shared as is, with no guaranteed response time.
